01 模型积分是如何结算的？ 基本倍率 积分以 0.004 元/K tokens 为基准单价，每 1K 积分 对应 1K tokens 的基准用量。不同模型按刊例价折算出 价格系数 （= 模型刊例价 ÷ 0.004），实际消耗积分 = 用量（K tokens）× 价格系数。 额外倍率 部分新上线或资源紧张的模型会在基本倍率之上叠加 额外倍率 ，最终消耗积分 = 用量（K tokens）× 基本倍率 × 额外倍率。额外倍率会在模型详情页标注，并在资源充足后适时取消。 计算示例 以 GLM 5.1 为例（输入刊例价 0.006 元/K，基本倍率 = 1.5，暂无额外倍率）： 每 1K 输入 tokens 消耗 1.5K 积分 若订阅含 50 亿积分，可换算约 33 亿输入 tokens （50 亿 ÷ 1.5），按刊例价折算约价值 2 万元 倍率越高的模型消耗越快，建议结合主要使用的模型估算所需积分量。 02 我可以同时购买多个订阅吗？ 单个团队账号当前仅支持同时拥有 一条生效中的订阅 。不同产品线的方案 不可叠加购买 （避免模型权益重复）。在同一产品线内仅支持 升级 至更高档位，不支持在生效周期内降级。 03 订阅内的模型是否会随时变动？ 订阅内模型会根据市场与技术动态适时优化， 重大调整将提前通知 ，保障用户体验连续性。 04 如果团队额度用完了怎么办？ 周期额度用完 ：耐心等待下一个刷新周期，额度将自动恢复 全部额度用完 ：通过按量付费模式的 API Key 继续使用服务，或升级至更高等级的订阅计划 05 API 访问权限如何保障安全？ 订阅仅能通过订阅 API Key 访问，可以前往 API Key 管理 管理你的订阅访问。 06 可以随时升级或取消计划吗？ 升级 ：升级后权益立即生效 取消 ：通过取消续订方式生效，当前订阅周期内服务不变，到期后自动终止 目前暂 不支持降级 07 订阅的积分额度没用完会不会过期？ 所有订阅计划的额度遵循**“订阅周期清零”**规则，不累计至下一周期。 订阅周期分别为： 包月 30 天 、 包季 90 天 、 包年 365 天 。请合理规划用量。 08 "每周刷新额度"具体是什么意思？ 系统 每周
