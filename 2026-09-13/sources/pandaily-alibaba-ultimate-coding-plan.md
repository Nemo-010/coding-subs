Title: Alibaba Cloud Launches “Ultimate Coding Plan” with Four Top-Tier Open-Source Models

Alibaba Cloud is redefining AI coding subscriptions by enabling developers to freely switch among multiple top-tier open-source models under a single plan.

On February 25, Alibaba Cloud Model Studio unveiled its most powerful Coding Plan to date, offering API access to four leading open-source models—Qwen3.5, GLM-5, MiniMax M2.5, and Kimi K2.5. With a single subscription, users are no longer limited to a single model and can freely switch among multiple models, benefiting from greater stability and significantly higher token quotas. Currently, Alibaba Cloud is the only global cloud provider offering this type of multi-model coding subscription service.

The Coding Plan Lite entry package supports up to 18,000 requests per month, with a USD 1 first-month price for new users. The Pro package supports 90,000 requests per month, enabling thousands of complex coding tasks, and costs just USD 5.5 for the first month for new subscribers—dramatically reducing costs for high-frequency coding scenarios. After subscribing, users can seamlessly access these models across AI developer tools such as Qwen Code, Claude Code, Cline, and OpenClaw.

All four newly launched models are top-tier open-source offerings. Qwen3.5, a native multimodal model open-sourced on Lunar New Year’s Eve, delivers industry-leading efficiency and cost-performance, with 397 billion total parameters and only 17 billion activated, achieving strong results across reasoning, programming, and agent benchmarks. GLM-5 is the latest flagship open-source model from Zhipu AI, whose API services have seen overwhelming demand since launch. MiniMax M2.5 is natively designed for agent-centric use cases and excels in advanced Excel processing, deep research, and PPT and other Office scenarios. Kimi K2.5 has also delivered significant upgrades in coding and agent capabilities.

With this release, Alibaba Cloud Coding Plan now includes eight top-tier programming models, making it one of the most comprehensive subscription offerings currently available. The Alibaba Cloud Model Studio platform also provides API access to more than 100 mainstream domestic and international models, along with over 400 agent templates and services spanning AI hardware, short video, advertising, and other enterprise-focused scenarios—meeting a broad range of enterprise AI needs.
